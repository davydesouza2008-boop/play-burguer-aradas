# Performance

`index.html` é a versão recomendada para publicação e PageSpeed: usa imagens externas otimizadas em WebP.

`index-portable.html` é uma versão de ficheiro único com imagens embutidas, útil para pré-visualização/offline, mas mais pesada e não recomendada para PageSpeed.

Em alojamentos como Vercel, Netlify, Cloudflare Pages ou GitHub Pages, a compressão Gzip/Brotli costuma ser aplicada automaticamente.
